# Единое ТЗ по улучшению UI / UX (endgame.md)

Документ объединяет технический аудит кода (`theme/templates/*`, `modules/*/templates/*`, `theme/css/main.css`, `scripts/studydb.js`, `api/index.php`), продуктовые идеи (`tasks/ui/ui_ideas.md`) и замечания к целевому макету (`tasks/ui/ui_ex.png`).

---

## Приоритеты и этапы

| Этап | Что сделать | Эффект | Сложность |
|---|---|---|---|
| **1** | `<meta name="viewport">`, поиск по `Enter`, кнопка «Расширенный поиск» + счётчик фильтров, параметры в URL | Работает на мобильных, можно делиться ссылками, фильтры очевидны | Низкая |
| **1** | Шапка на Flexbox, текстовая ссылка «Войти» вместо «гамбургера», активный пункт меню, чистка футера | Понятная навигация, доступный вход, без багов `:hover` | Низкая |
| **2** | Новая карточка на CSS Grid, иерархия (автор/источник → доска → бейджи → кнопки + мелкий PID), `Copy FEN`, `<a download>` для PGN | Быстрая читаемость, доски не «прыгают», удобное копирование и скачивание | Средняя |
| **2** | Полноценная пагинация (сверху/снизу, номера страниц), сортировка, состояния загрузки / ошибки / пустого результата | Удобная работа с сотнями позиций, нет зависания UI при ошибках | Средняя |
| **2** | Доработка модального окна `PGNLive!` (backdrop, `Esc`, клик вне окна, спиннер) | Комфортный просмотр решения этюда | Низкая |
| **3** | Расшифровка условий (`tt22#016 {m}` → «Мат в 16 ходов`), бейдж «Ход белых / Ход чёрных» из FEN, 3-позиционный переключатель `cooked` | Понятно новичкам, информативные карточки и фильтры | Средняя |
| **3** | Автодополнение автора/темы, UI для `piece_pattern`, улучшение формы добавления этюда (`endgame-form.template.php`) | Полноценный поиск и удобный ввод новых этюдов | Средняя |
| **4** | Локализация (`RU / RO / EN`), страница отдельного этюда, режим «Решить самому», случайный этюд / этюд дня | Рост вовлечённости и охвата аудитории | Высокая |

## 1. Шапка, навигация и авторизация

**Файлы:** `theme/templates/index.template.php`, `theme/templates/loginform.template.php`, `theme/templates/usermenu.template.php`, `theme/css/main.css`

### Задачи
- [ ] Добавить `<meta name="viewport" content="width=device-width, initial-scale=1">` в `<head>` (`index.template.php`).
- [ ] Уменьшить заголовок сайта и сделать его ссылкой на главную страницу.
- [ ] Перевести `.navbar` на Flexbox (`display: flex; align-items: center; flex-wrap: wrap; gap: 1.5rem;`), убрать фиксированные `one column` у ссылок навигации.
- [ ] Подсвечивать активный маршрут классом `.navbar-link.active`.
- [ ] Подписать `FENBuilder` понятнее (например, «Конструктор позиции (FEN)») и исправить путь `/../builder/` / двойные слэши.
- [ ] Для страниц `About` и `Links` предусмотреть чистые URL (`/about`, `/links`) или корректную подсветку текущих маршрутов.
- [ ] Заменить скрытый `:hover`-дропдаун (`ddmenu.png`) на явную кнопку **«Войти»** в шапке (на узких экранах — компактное меню с `aria-label`). После входа показывать имя пользователя с выпадающим меню по **клику** (`position: absolute; right: 0; top: 100%;`) и закрытием по клику вне меню.
- [ ] Убрать дублирующий `id="login-form"` у ссылки `Log Out` в `usermenu.template.php`.
- [ ] Предусмотреть переключатель языка (`RU / RO / EN`) в шапке (этап 4).

## 2. Поиск, фильтры и URL

**Файлы:** `modules/endgame/templates/endgame-search-form.template.php`, `scripts/studydb.js`, `api/index.php`

### Задачи
- [ ] Обернуть форму поиска в `<form onsubmit="event.preventDefault(); getPosition(0);">`, чтобы поиск срабатывал по `Enter` в любом поле.
- [ ] Убрать `onfocus="showAdvanced()"` с поля `author` и принудительное скрытие `#advanced` после поиска в `getPosition()`.
- [ ] Добавить явную кнопку-переключатель **«Расширенный поиск ▾ (фильтры: N)»** с `aria-expanded` и `white-space: nowrap` (чтобы счётчик не переносился на вторую строку, как на макете `ui_ex.png`).
- [ ] Выровнять подписи полей, сделать кнопку **«Найти» / «Search»** главной (`.button-primary`), а **«Сбросить» / «Clear»** — вторичной (контурной).
- [ ] Хранить параметры поиска в URL (`?author=Kubbel&stipulation=...&sort=...&page=...`) через `history.pushState` / `URLSearchParams`, а при загрузке страницы восстанавливать форму и выполнять запрос.
- [ ] Заменить чекбокс `Is cooked` на переключатель из трёх состояний: **Все | Только корректные | Только с дефектами** — оформить в виде segmented control или явных радио-кнопок с активным состоянием и подсказкой.
- [ ] Передавать параметр `cook` в `getPdf()` (сейчас он теряется при экспорте PDF).
- [ ] Добавить сортировку результатов (по году, автору, числу фигур) — на бэкенде в `api/index.php` и в селекте над карточками (ширина селекта должна вмещать текст без обрезки).
- [ ] Добавить автодополнение по автору и теме (вместо длинного `<select>` со всеми темами) и продумать UI для `piece_pattern` (сейчас `patternMake()` возвращает `""`).

## 3. Карточки результатов, доска и пагинация

**Файлы:** `scripts/studydb.js`, `theme/css/main.css`, `api/index.php`

### Задачи
- [ ] Заменить `float: left` и фиксированные `300×500px` у `.dd` на адаптивный **CSS Grid** (`display: grid; grid-template-columns: repeat(auto-fill, minmax(280px, 1fr)); gap: 24px;`), убрать устаревший тег `<center>`.
- [ ] Изменить иерархию карточки по макету `ui_ex.png`:
  1. **Шапка карточки:** Автор (крупно), источник и год (под ним). Ограничить высоту шапки (`min-height` + `-webkit-line-clamp: 2`), чтобы длинные названия источников (например, *Listok Shakhmatnogo Kruzhka Petrogubkom*) не сдвигали доску относительно соседних карточек.
  2. **Диаграмма:** шахматная доска (мягкая заливка на экране, штриховка остаётся для PDF, координаты `a–h`, `1–8` опционально), клик открывает просмотр/увеличение.
  3. **Бейджи:** «Ход белых» / «Ход чёрных» (из FEN), условие («Белые выигрывают», «Ничья», «Мат в N ходов» — расшифровка кодов вроде `tt22#016 {m}` с сырым кодом в `title`).
  4. **Футер карточки:** компактные кнопки `PGNLive`, `PGN` (прямая ссылка `<a href="?q=pgn/#pid#" download>` вместо `window.open`), `FEN` (кнопка копирования в буфер обмена вместо редактируемого `<input>`) и мелкий серый `PID` справа.
- [ ] Оптимизировать рендер списка в `studydb.js`: собирать HTML в переменную и вставлять в `#diag` одним присваиванием вместо `innerHTML +=` в цикле.
- [ ] Обернуть `request()` в `try/catch`: показывать индикатор загрузки, корректное сообщение об ошибке и понятное пустое состояние («Ничего не найдено. Попробуйте убрать фильтр»).
- [ ] Обновить шапку результатов: исправить `"no more then 1000 diagrams per PDFfile"`, оформить кнопку **«Скачать PDF»** в одну строку (`white-space: nowrap`) на одном уровне с сортировкой.
- [ ] Заменить гиф-стрелки `left.gif` / `right.gif` на полноценную пагинацию с номерами страниц (`Назад`, `1`, `2`, `3`, `...`, `Далее`) и продублировать её под сеткой результатов.
